# Archived: exarp-go llama.cpp / GGUF path

These documents described a **removed** integration (direct GGUF inference via go-llama.cpp, optional `llamacpp` tooling, and related benchmarks). **exarp-go does not ship this stack.**

For local LLMs, use **Ollama** (`ollama` tool, `text_generate` with `provider=ollama`) or **Apple FM** (`text_generate` with `provider=fm` where available).

Historical files in this folder are unchanged aside from being moved under `docs/archive/llamacpp-removed/`.
